和 SkulInsight 的"冷却秒表"互补：一个显示**还剩几秒**，一个显示**这次冷却是被拉长还是缩短**。

纯逻辑修改，不改数值、不加文本、不影响存档。

## 6. DevMenuZhFix 0.1.0（DevMenuTurbo 补充汉化 · 自研）

安装位置：`BepInEx\plugins\DevMenuZhFix\DevMenuZhFix.dll`
源码：`D:\Game\Learning\Skul\_src\DevMenuZhFix\`

### 为什么需要它

`lostone/DevMenuTurbo_ZH` 的汉化只覆盖了 `Panel.Awake` 里的 24 个控件，剩下四个面板全没动。我反编译核对了游戏原版 `UI.TestingTool` 的全部字段，把漏掉的逐个补上：

```csharp
Panel.Awake / OnEnable / Revive / InitReviveCount   → 章节按钮、地图/种子、版本、复活计数
GearList.Awake                                      → 头骨/道具/精华/升级、两个开关、搜索框
DataControl.Awake                                   → 12 个按钮 + 2 个滑条
Log.Awake                                           → 复制 / 清除
```

关键点是 `_mapName`、`_version`、`_reviveCountText` 这三处**每次打开菜单都会被游戏重新赋值**，所以不能只在 `Awake` 里改一次——`OnEnable`、`Revive`、`InitReviveCount` 三个入口都挂了同样的修正。

### 实现细节

- 用 `HarmonyPriority(Priority.Low)` 排在 DevMenuTurbo 之后，避免被它覆盖
- 文本替换而非硬写：`부활횟수` → `复活次数`、`Map :` → `地图：`，保留游戏填进去的实际数值
- 按钮取 `GetComponentInChildren<TextMeshProUGUI>(true)`；滑条取**第二个** TMP（第一个是当前值）
- 字段全是 `private`，用 `AccessTools.Field` 反射读写

### 和 DevMenuTurbo 的关系

**必须先装 DevMenuTurbo**（它负责解锁菜单本身），本插件只做文本补充。单独装它没有任何效果，也不会报错。

## 排错速查

| 现象 | 处理 |
|---|---|
| 想看加载了哪些 mod | `BepInEx\LogOutput.log` 搜 `Loading [` |
| 某 mod 有没有 hook 失败 | 同上搜 `SelfTest`，PASS/FAIL |

| 游戏启动但没有任何 mod 效果 | 检查 `winhttp.dll` 是否被杀软删掉 |
| 全卸 | 删 `BepInEx\`、`winhttp.dll`、`doorstop_config.ini`、`2020.3.34\` |
